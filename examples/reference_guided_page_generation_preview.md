# 历史样本如何指导页面生成｜真实示范

## 1. 本次匹配的历史样本

- **参考文件**：`26_0610 PRESENTATION_LR.pdf`
- **PDF 页码**：第 11 页
- **参考页型**：规划策略 / Planning Strategy
- **可学习内容**：四项连续策略、动作型短标题、图像卡片、递进箭头、中英双语层级
- **不可学习内容**：SKP、黄埔路、马场、公园位置、酒店布局及历史方案结论

### 原页表达结构

原页不是一篇连续正文，而是四张并列策略卡：

1. 外部商业联动与门户形象；
2. 酒店布局与景观视野；
3. 场地与公园边界融合；
4. 立体步行与复合社区。

从中抽取出的不是原项目答案，而是下面这个表达公式：

`策略编号 → 关键动作 → 作用对象 → 空间结果或项目价值`

## 3. 传给单页生成器的页面指导包

### 页面任务

- **目标页型**：strategy
- **页面标题**：总体策略 / Planning Strategy
- **核心信息**：通过四项连续动作，把城市公园、文化功能、滨水空间与交通组织整合为完整公共系统。

### 从历史样本继承的文字规则

- 使用四项并列策略，不写连续长文；
- 每项策略先写动作型标题，再写一条结果；
- 中文标题控制在 8–16 字；
- 每项只表达一个动作，不在同一卡片中混合多个判断；
- 四项内容形成由外部连接到内部组织的推进关系；
- 英文是次级信息，不与中文争夺视觉层级。

### 从历史样本继承的版式规则

- A3 横版；
- 左上角设置章节名和英文副标题；
- 页面主体为四个等宽竖向卡片；
- 每张卡片顶部显示红色策略编号；
- 主图加浅色蒙版，保证标题可读；
- 卡片之间使用箭头表达连续推进；
- 页面不增加大段正文和独立结论框。

### 当前页禁止项

- 不得出现历史项目名称、道路、商业体、酒店和公园结论；
- 不得增加当前资料没有确认的入口、连桥、材料或空间形态；
- 不得为了模仿历史文风而改写当前项目事实；
- 不得使用没有当前来源页码支持的数字。

## 4. 按照上述指导生成的新项目页面文本

### 总体策略

**策略一｜接入城市公园**

以首层架空通廊和可步行公共屋面串联城市公园、文化大厅与滨水平台，形成连续开放的公共路径。

**策略三｜聚合文化客厅**

**策略四｜分离到达流线**  
观众由公共界面进入，后勤车辆从场地东侧独立到达，减少不同使用路径之间的干扰。

## 5. A3 页面生成指令

页面生成器不只接收上面的文字，还应得到以下图面指令：

1. 将四项策略制作成等宽竖向卡片；
2. 卡片顺序为“城市连接—滨水连续—功能聚合—交通分离”；
3. 每张卡片配置一张与本策略对应的当前项目图像；
4. 图片不足时显示明确的图像占位框，不使用历史项目图片；
5. 使用红色编号建立节奏，正文保持深灰色；
6. 中文为主要信息，英文缩小一级；
7. 每张卡片只保留标题和一条结果说明。

## 6. 生成后的双重审核

### 事实审核

- “城市公园”“轨道站点”“滨水平台”“南北两翼”“中央公共大厅”“东侧后勤入口”均必须回指当前项目资料；
- 如果当前项目没有确认某一项内容，对应策略应显示为待补信息，不得从历史样本补齐。

### 风格审核

- 是否保持四项并列；
- 标题是否为动作型短句；
- 是否符合“一项策略，一个判断”；
- 页面是否由图像卡片主导；
- 是否错误复用了历史项目名词或原句。

## 结论

精选样本库不会直接替用户生成内容。它的作用是为每一张目标页面提供一套“文字结构、版式结构和禁止项”。真正生成时，系统先按页型找到历史样本，再把样本抽象成规则，最后只用当前项目事实填充。这样才能同时获得相似的汇报语言和不同项目之间的事实隔离。
